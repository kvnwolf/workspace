## Philosophy: Fight Entropy

- Make illegal states unrepresentable through types and data structures
- Prefer minimal, surgical changes over broad refactors
- Leave the codebase better than you found it
- NEVER add comments in code — the code must be self-documenting
- NEVER make atomic edits that only add imports — always include the code that uses them in the same edit

## Communication

- Always communicate in the same language as the user. Default to SPANISH if the user hasn't specified a language
- IMPORTANT: code, documentation, and any text for purposes other than conversation must be written in ENGLISH
